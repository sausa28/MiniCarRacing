# Mini Car Racing

Mini Car Racing is an old obscure PC game (that is lots of fun) that I've tried to get running on modern PCs.  It should run fine with just the 3 files in the game directory.

I'm also attempting to reverse engineer the game. Not with any particular goal, but to learn how to do so and figure out how the game works. Maybe I'll eventually create some mods or something :3

ddraw.dll is provided by https://github.com/narzoul/DDrawCompat to improve compatibility with modern windows.

## To run
Windows: simply run minicarracing.exe in the game directory.

Linux: Add minicarracing.exe as a non-steam game in steam and run from steam.
